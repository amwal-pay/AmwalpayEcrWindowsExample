Amwal ECR Example (Windows)
===========================
Double-click AmwalECR.Example.exe. Nothing to install: .NET is bundled.
(Windows 10 1809+ / Windows 11. If SmartScreen warns, choose More info > Run anyway:
the build is unsigned.)

Try it without a real terminal
------------------------------
1. Install Python 3, then in this folder run:
     python tools\fake_pos_server_signed.py --key 0123456789ABCDEF0123456789ABCDEF --port 19100
   (flags: --decline 51, --partial, --delay 3, --drop-sale, --not-found)
2. In the app open Terminals (top right):
     Wi-Fi secure hash key: 0123456789ABCDEF0123456789ABCDEF
     Add terminal: Serial TW1234567890, Mode Wi-Fi, IP 127.0.0.1, Port 19100
3. Back on the main screen: pick the terminal, Sale, key an amount, Start transaction.

Real terminal: register its IP (shown on its idle screen), port 9100, and the Wi-Fi
signing key configured on that terminal. Web Service terminals need Amwal credentials
(environment, Web Service key, merchant ID, terminal ID); there is no fake for them.

USB cable: plug the terminal in with its virtual serial port turned on. Add a
terminal with mode USB cable and choose the MediaTek USB VCOM device
(115200, 8 data bits, no parity, 1 stop bit). Windows assigns the COM port
from that device's serial number, and the number can change. Save the
terminal again after plugging it in so the till remembers the serial.
Use the same Wi-Fi signing key.

Good to know
------------
- Cancel only stops waiting. If the request already reached the terminal the payment may
  still complete: the app then shows "Outcome unknown". Use Inquire by reference; never
  repeat the sale.
- Close receipt (on a finished sale, void or refund) clears the terminal's receipt screen.
  Closing the result window does not.

Your data is in %APPDATA%\AmwalECR-Example (terminals.json, and settings.dat
encrypted with your Windows account).
